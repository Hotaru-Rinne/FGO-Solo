# 一骑千筹 0.4.3

Android 与 Windows 同步更新。

- 各职阶冠位星图新增默认增益：仅影响伤害的红／蓝／绿魔放各 50%，每回合 NP 获取 10%，EX 卡性能 200%。
- 仅在勾选“启用冠位职阶星图”后生效，各职阶可以独立修改。
- 旧设置或旧备份首次升级时补齐这五项中的缺失值和 0 值，保留非零自定义值；此后主动改为 0 会正常保存。“恢复当前职阶默认值”也使用新数值。
- 两版共享同一套计算核心；补充双平台 GitHub 发布教程。

下载 Android 请选 FGO-Solo-0.4.3.apk；使用原签名，可覆盖旧版。
下载 Windows 10/11 x64 请选 FGO-Solo-Windows-0.4.3-x64.zip，完整解压后运行“一骑千筹.exe”。请保留同目录的其他文件。

Source code 是源码，不能直接作为应用安装。SHA256 文件用于核对下载文件。
