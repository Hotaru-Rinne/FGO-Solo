# 一骑千筹 · Windows 版

版本 0.4.2，适用于 Windows 10/11 的 64 位 Intel/AMD 电脑。

## 运行
将压缩包完整解压到一个文件夹，双击“一骑千筹.exe”。无需安装 Node、Java、Android SDK 或额外浏览器；计算与内置资料离线可用。
不要只复制一个 exe，也不要直接在压缩包里运行。保留同目录所有运行文件。可右键 exe 创建桌面快捷方式。
此版为免安装桌面软件，未购买代码签名证书。

## 与手机版相同的功能
从者选择与编辑、变身相邻排序、星图与硬币被动、各卡配置、最多六名敌人、计算与下一回合、Atlas 增量获取与 Mooncell 名称补全、纹章速查、背景、数据备份和手动更新均保留。
界面会跟随窗口大小变化，双击标题栏最大化；F11 切换全屏。
外部链接由 Windows 默认浏览器打开。更新检查识别 Windows 的 exe 或带 Windows/win-x64 标识的 ZIP，不会把 APK 当作电脑版更新。

## 本地数据与手机迁移
设置、计算与从者数据自动保存在当前 Windows 用户的 %APPDATA%\FGO-Solo 目录；没有云同步。
手机与电脑使用相同的 JSON 备份格式：在安卓设置中导出备份，传到电脑，再在电脑版设置中导入。反向操作也可以。
导入会替换相应的本机配置；背景图片也包含在备份中。导出时使用系统“另存为”对话框，可自己选择目录。

## 升级
先在设置里导出备份，然后关闭软件。将新版本完整解压到新文件夹并运行，原用户数据会自动读取。不要把新版文件与运行中的旧版混合复制。
Windows 第一个版本与 Android 0.4.2 共用版本号和计算核心。正式发布 GitHub Release 时，把电脑版 ZIP 与安卓版 APK 一起附加；源码 ZIP 不作为 Windows 安装文件。

## 数据获取
需要联网时才请求 Atlas、Mooncell 或 GitHub。已有 ID 按约定跳过，既有从者的强化不会自动覆盖。
若网络无法访问相应网站，界面会报告失败，可以稍后重试；已成功保存的记录保留。
特殊从者的自动识别边界与手机版相同，首次录入后可在“数据识别记录”中核对。
