# 一骑千筹 · FGO 单挑计算器

当前版本：**1.0.0 正式版**（2026-10-13）。Android / Windows 离线计算器，支持在应用内从 Atlas Academy 日服数据库获取新增从者，并向 Mooncell 补全中文名称。

安装文件：`dist/FGO-Solo-1.0.0.apk`。使用与旧版相同的应用 ID 和签名，可直接覆盖升级。建议先在设置中导出一次备份。

## Windows 桌面版

Windows 10/11 x64 安装版：`dist/FGO-Solo-Windows-1.0.0-Setup-x64.exe`，按提示安装。免安装版：dist/FGO-Solo-Windows-1.0.0-x64.zip。完整解压后运行“一骑千筹.exe”。

与安卓共用完整界面及计算核心，支持背景、本地数据、系统备份保存和手机备份互导。使用说明见 [Windows使用说明](docs/Windows使用说明.md)，构建及发布见 [Windows开发说明](docs/Windows开发说明.md)。

## 已有功能

- 普通职阶星图和冠位职阶星图均按职阶独立保存。
- 硬币 EX 卡性能、暴击威力、逐职阶及 EX 职阶加攻全部保存在每名从者的数据中，只有首页勾选时生效，移除全局硬币设置。
- 首页和设置的从者列表按 Atlas 图鉴编号从新到旧排列；通过变身函数中的目标 ID 将本体与变身形态相邻排列，本体在前。
- 设置可删除任意从者；删除会移除覆盖和下载记录，内置项的删除也会持久保存，可再次获取。删除当前从者会切换到下一可用从者，空库仍可进入设置。
- 默认 120 级、宝具 5 级、额外 ATK 4400，三项默认值均可设置，适用于新计算和切换从者。
- 默认竖屏，设置可选横屏或跟随手机；横屏保留输入，不重启页面。
- 每名敌人新增 A 类减益、降防、C 类减益、D 类特攻和固定伤害；D 类从我方页面移除，改为逐敌人填写。
- 增加从者自身的对职阶攻击相性字段，适配杀生院、C.I.E.L 等常驻相性覆盖。
- 新建计算/重新选人默认 120 级、宝具 5 级；旧存档的已填等级不会被强行覆盖。
- “全体攻击减半”更名为“全体攻击”，结算规则保持不变。
- 已重新下载并替换全部 474 条内置记录：470 条常规索引记录和 4 条独立变身形态记录。28 条名称从 Mooncell 补全，本次没有名称查询未匹配项。

## 安装与使用

1. 将 APK 传到 Android 8.0 或更高版本的手机安装。需要支持现代 JavaScript 的系统 WebView，建议 108 或更高。
2. 在开始界面点击“开始计算”，选择从者，设置等级、宝具等级、额外 ATK，并按需启用星图和硬币被动。
3. 配置通用增益、四张指令卡及单卡特殊选项，再设置最多 6 名敌人并计算。
4. 关闭结果后，进入下一回合才会扣除敌方 HP；全部增益和指令卡输入保留。
5. 右上角设置可编辑或删除从者、单独修改其硬币数值、调整星图、默认养成、屏幕方向、背景及备份。
6. “设置 → 从者数据获取 → 获取新增从者”会访问 Atlas。已有 ID 不再请求详情，不覆盖手动修改。网络中断或停止后可再次点击继续。

计算、背景和已下载数据离线可用；获取数据、启动检查更新或下载更新时需要网络。背景图片保存在本机，不上传。应用内网络用于 Atlas / Mooncell 公开数据和 GitHub 发布查询，不请求全盘照片库权限。

## 硬币数值的填写方式

- 从者自带攻击适性储存在该从者的数据中，例如阿尔托莉雅的对 Rider 加攻 30%。仅开启硬币被动后应用。
- “设置 → 从者数据 → 内置被动数值 → 从者硬币被动”分别保存该从者的 EX 性能、暴伤、对职阶加攻。
- 例如从者对 Rider 的实际养成只有 20%，直接把该从者的“对 Rider 加攻”改为 20%。
- “对 EX 职阶额外加攻”叠加到非剑、弓、枪、骑、术、杀、狂、其他的目标，包括盾及各额外职阶。
- 攻击适性进入 B 区；相性被动作用于职阶相性项。二者不混用。
- 敌方自定义职阶倍率优先于自动职阶相性，但不会关闭正常的对职阶加攻。

## 数据获取与常态被动

数据来自用户指定 Atlas JP 从者数据库的结构化 API。中文名称优先使用简中名称对照；未翻译时请求 Mooncell 编号页，未找到则按“从者内部id”语义查询，再核对基础数值区块的内部 ID，提取对应中文名。变身形态独立核对，搜索仍支持原名。没有匹配或请求失败时保留原名并记录原因。Mooncell 请求在 Android 上使用原生 HTTPS 层，避免部分 Chromium/WebView 直连兼容问题。

匹配粒度是单个效果：

- 直接、无限期、无概率/场地/状态等条件的数值被动可录入。
- 卡色是数值适用范围，不当作需要手动触发的条件。
- 计算从者在场时会持续作用于其自身的全队常驻被动，计入自身；只作用于其他队友的效果不计。
- 条件效果与触发型效果不展开；同一技能中的其他常驻部分仍可录入。
- 硬币 EX 性能、暴伤和攻击适性与常态被动分开保存。魔力装填、再装填及狂阶的暴击耐性不当作本次攻击收益。
- 每个从者的设置中提供“数据识别记录”，可查看已录入/排除及原因。

你提供的真实样本已经验证：逆光 EX 不录入触发增益；原初之一的千年城魔放排除；Moon Cancer Kingprotea 常驻 3 星录入、水边 2 星排除。

## 数据边界

- 日服宝具采用可用的强化后版本，附加效果、条件特攻、宝具前置增益等仍由玩家在计算页填写，不自动模拟技能发动。
- 两种宝具分别保存颜色、倍率、NP 率、Hit/OC Hit 分布。多于两种形态的原始候选也保留，可在从者设置中选择宝具 2 使用的形态。
- 少数变身形态的 API 没有独立硬币技能列表，不凭名称猜测继承；相应记录会提示需手动补充。
- 少数原始 Hit 权重合计不是 100；保留原始权重，并按总权重缩放命中伤害。
- 增量获取按 ID 只新增。已有从者未来的强化变更不会被该按钮自动覆盖；可手动编辑，避免覆盖用户自己的修正。

## 工程结构

- `src/model.js`：字段、默认值和术语。
- `src/engine.js`：不依赖界面的计算核心。
- `src/atlas-import.js`：数据获取、增量跳过、被动/宝具识别。
- `src/mooncell.js`：中文名补全及内部 ID 核验。
- `src/catalog.js`：从者排序、变身分组及旧配置迁移。
- `src/validation.js`：从者及备份校验。
- `src/pages.js`、`settings-view.js`：步骤与设置界面。
- `src/start-pages.js`、`guide.js`：开始菜单及离线文档。
- `src/updates.js`、`release-config.js`：GitHub 版本检查和官方仓库配置。
- `public/docs/command-code-random.txt`：纹章速查纯文本正文。
- `src/app.js`：输入、导航及数据获取协调。
- `src/storage.js`：计算存档、背景和新增从者持久化。
- `public/data/`：内置从者快照和中文名对照。
- `android/`：安卓原生容器及文件选择/保存。
- `tests/`：公式、数据解析、备份校验及界面测试。
