0随机数的效果：

暴伤/特攻

暴击星掉落率增加

无视防御

无敌贯通

固伤

指令卡NP获取率增加


1随机数的效果：

生命恢复

出星

弱化解除（即使无效也是1随机数）

敌方特定buff解除（即使无效也是1随机数，暴击威力提升/暴击率提升/宝具威力提升解除除外，以上三类效果如果敌方没有此类buff则随机数为0）

对敌方施加效果（dot/罗马/debuff，敌方有弱化无效则为0随机数）

对我方施加效果（一回合一次性暴伤/一回合一次性红放/贤狐纹章/玛修纹章的一次性buff被消耗不会影响随机数）

弱体无效类（封印无效/无法行动/降防无效）（此类buff挡了对面debuff会影响随机数，因为本来对面开控制类效果是会消耗随机数的，但是如果被绿人顶了就会变成不消耗随机数了）是极少数能在敌方行动时改变后续行动的手段，也就是说即使我方回合随机数一样，在敌方回合有/没有挡掉debuff，后续的行动会不一样）

梅林纹章（1随机数，但如果处于cd状态，则为0随机数）

贞德纹章（同上）

在施加效果前进行判定（老虎机/狮子王纹章，因此这两个纹章是2随机数）


2随机数的效果：

所有组合了2个1随机数效果的纹章均为2随机数，需要特别注意的是：

纹章效果为“解除敌方某buff，如果解除成功则为敌方施加某debuff”的纹章，如果敌方没有能解除的对应buff，为1随机数，有则是2随机数。


3随机数的效果：

所有组合了3个1随机数效果的纹章均为3随机数，需要注意的是：

梵高向日葵纹章上的诅咒被自己的绿人挡掉会导致只有2随机数（参考1随机数中的debuff类介绍）

注：极个别特殊副本会导致纹章随机数乱掉。
